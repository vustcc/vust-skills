# VUST 品牌视觉规范

本文档定义 VUST 各项目和 Skill 共用的稳定品牌原则。VUST 是一个可扩展的分布式 Linux 主机运维平台，用于统一管理一台或多台 Linux 主机，并支持通过套件按需扩展平台能力。具体 UI Token、组件与图标实现以消费项目当前安装版本的 `@vustcc/*` 公开包为准；本文档不替代运行时包或类型声明。

## 品牌定位

- 产品名称：VUST。
- 产品类型：可扩展的分布式 Linux 主机运维平台。
- 核心气质：工程化、可观测、可信、克制、清晰。
- 用户感受：专业工具而非营销页面，操作可预测，状态可辨识，信息可快速扫描。

## 色彩语义

| 语义 | 基准色 | 使用范围 |
| --- | --- | --- |
| 品牌蓝 | `#1D63ED` | 浅色主题主操作、关键选择和产品图标强调。 |
| 通信青 | `#00C8FF` | 深色主题主操作、通信、扫描和实时状态。 |
| 辅助青绿 | `#00D4B4` | 成功、连接、健康和次级品牌强调。 |
| 仿真紫 | `#7C6CFF` | 仿真、规则、实验和抽象协议能力。 |
| 警告琥珀 | `#FFB547` | 等待、风险提示和需要注意的状态。 |
| 危险红 | `#FF5E7A` | 失败、高风险、删除和破坏性操作。 |
| 结构蓝灰 | `#344A72` | 应用和套件 PNG 图标的主体结构。 |

规则：

- 品牌色用于强调，不用于大面积装饰背景。
- 状态色必须保持固定语义，不按页面喜好随意交换。
- 浅色和深色主题都必须提供足够对比，不能只依靠阴影或发光分离内容。
- 应用图标的暗部不得接近纯黑并连成一片；40px 下仍应区分主要结构面。
- 禁止由单一蓝色或蓝紫渐变统治整个界面或整套资产。

## 视觉语言

- 使用稳定网格、清晰层级、紧凑间距和直接视觉隐喻。
- 优先展示真实产品、对象、状态、数据和操作结果。
- 装饰必须服务于辨识或层级，不添加无功能的视觉噪声。
- 应用和套件图标采用轻量立体 PNG；通用操作和状态图标采用可主题化 SVG。
- 圆角保持克制，业务卡片通常不超过 8px；不使用卡片套卡片。
- 默认主题为浅色，同时保证深色主题可读性。

## 禁用元素

- 黑客人物、骷髅、武器、绿色字符雨和攻击性游戏符号。
- 大面积霓虹、科幻 HUD、发光描边、蓝紫渐变和装饰性 orb/blob。
- 卡通吉祥物、贴纸感、玩具化拟物和与安全工具无关的插画。
- 无授权的第三方商标、产品 logo、角色和品牌视觉。
- 为表现“科技感”而增加的无语义网格、线路、粒子或背景纹理。

## Logo 使用边界

- VUST Logo 只用于产品身份、启动、登录、favicon 和明确的品牌场景。
- 功能应用和套件不得把 VUST Logo 当作通用图标主体。
- 不拉伸、旋转、重绘或改变 Logo 的结构比例。
- 不把 Logo 与第三方标识组合成未经定义的新标识。
- 需要新增正式 Logo 变体时单独建立品牌资产任务，不由应用图标生成流程临时派生。

## 事实来源

按消费项目当前版本解析事实，不要求固定源码目录。优先级为：消费仓代码与依赖声明 → 当前安装包的公开入口和类型 → 可选本地 `vust-ui` 源码 → 官方 GitHub 定位信息。远端最新分支不得覆盖已安装版本。

| 内容 | 公开来源 |
| --- | --- |
| 品牌原则与视觉边界 | 当前 skill 内置的 `references/vust-brand.md` |
| UI 颜色、字体、间距、圆角和主题 Token | `@vustcc/tokens` 的 CSS 导出 |
| Vue 3 基础组件 | `@vustcc/vue` 的公开导出与 `.d.ts` |
| React 19 基础组件 | `@vustcc/react` 的公开导出与 `.d.ts` |
| 通用 SVG UI 图标 | `@vustcc/icons` 的公开导出 |
| 应用与套件最终 PNG 资产 | 对应应用或套件消费仓库 |

`vust-ui` 官方仓库为 `https://github.com/vustcc/vust-ui.git`。它只作源码开发、共享契约和最终定位来源；skill 不自动 clone。
