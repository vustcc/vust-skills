# VUST 已确认应用图标家族

本文件记录用户已经确认的视觉方向。它提供设计基准，不存放或复制最终业务资产。

## 共同特征

- 轻量立体，不是扁平线性 SVG，也不是写实产品渲染。
- 主体为中亮蓝灰结构，使用一个语义强调色。
- 左上柔光、浅阴影、清晰外轮廓、克制材质。
- 无底板、无环境、无落地投影、无发光边缘。
- 40px 下保留主对象和层级关系，细节消失后语义不改变。
- 对象占画布比例接近，整套图标视觉重量均衡。

## 已确认基准

### Docker Manager

- 语义：三层容器堆栈加一个运行状态模块。
- 优点：容器对象直接，整体轮廓稳定，强调面清晰。
- 避免：容器门缝和暗槽过黑；不得使用 Docker 商标或鲸鱼。

### 套件中心

- 语义：互锁软件包集合加安装箭头。
- 优点：集合与安装动作同时明确，前后层级稳定。
- 避免：误像纸箱、购物包、压缩文件或下载器。

### Node Manager

- 语义：一个中心控制节点管理三个受管节点。
- 优点：中心控制节点体积明显更大，三个受管节点紧密停靠，整体形成饱满的一体化集群轮廓。
- 避免：松散星形拓扑、所有节点同权、圆柱数据库节点、简单立方体换色、发光连接、云或地球拓扑。

### 应用兜底

- 语义：四个中性软件模块组成通用应用占位图标，其中一个模块使用品牌蓝强调。
- 优点：在 16px 至 40px 下保持稳定网格轮廓，不对应任何具体业务应用。
- 避免：窗口交通灯、问号、感叹号、破图符号、齿轮、文件夹、套件包和警告语义。

### 系统监控

- 语义：桌面监视器内展示一条主要指标折线和少量资源状态。
- 优点：监视器轮廓稳定，绿色指标折线在 40px 下仍直接表达监控语义。
- 避免：多表盘车载仪表感、医疗心电图、复杂 Dashboard 缩略图和细碎指标。

### 文件管理

- 语义：开放文件夹包容一张文件页。
- 优点：文件夹是明确主对象，琥珀色标签和文件页打破整套图标的单一蓝色倾向。
- 避免：打印机、文件柜、纸箱、办公公文包、相册和下载器。

### 终端

- 语义：稳定终端窗口内包含一个大号命令提示符。
- 优点：窗口和提示符在 40px 下仍清晰，青色强调直接但不发光。
- 避免：复古终端机箱、纯黑方块、代码截图、绿色字符雨和霓虹提示符。

### 设置

- 语义：调节旋钮和滑杆组成集中配置面板，小齿轮只作次级信号。
- 优点：配置控制动作明确，旋钮与滑杆形成稳定层级，不依赖通用大齿轮。
- 避免：音频混音台、游戏设置、单独大齿轮、扳手和工具箱。

### 防火墙管理

- 语义：防护盾被一条红色网络边界环绕。
- 优点：盾牌轮廓和风险边界在 40px 下都清晰，安全语义直接但不具攻击性。
- 避免：复杂规则图、火焰、武器、警徽和黑客人物。

### 进程管理

- 语义：进程列表模块内只有一个活动进程显示运行脉冲。
- 优点：列表是稳定主对象，青色脉冲只强调当前运行状态。
- 避免：闪电符号、CPU 芯片、医疗心电设备和任务清单。

### 磁盘管理

- 语义：存储驱动器主体包含一个明确分区扇区。
- 优点：驱动器和分区语义集中在一个对象中，蓝色扇区在缩略图下仍可识别。
- 避免：底部状态条、光盘、数据库圆柱堆和云存储。

### 文件编辑

- 语义：带框文档与斜向编辑笔。
- 优点：蓝灰框维持家族视觉重量，文档和编辑动作层级清晰。
- 避免：无框轻量纸张、签名、邮件、画板和代码截图。

### 计划任务

- 语义：大时钟附带一组琥珀色任务条目。
- 优点：时间是明确主体，任务列表补充调度语义，40px 下仍可区分。
- 避免：普通闹钟、日历应用、秒表和过小任务模块。

### 脚本管理

- 语义：脚本文档放入执行模块，前方提供执行按钮。
- 优点：文档和执行动作组合完整，紫色用于脚本与仿真类能力。
- 避免：灰色弱执行信号、终端窗口、视频播放器、代码编辑器和魔法卷轴。

### 协议仿真

- 语义：协议测试舱内的两个模块进行双向数据交换。
- 优点：受控测试环境和协议交互同时成立，不依赖文字或波形。
- 避免：烧瓶、液体、化学实验、游戏控制器、传送门和灰色机械箭头。

### Web 浏览器

- 语义：带标签栏的浏览器窗口内展示一条网络路径。
- 优点：标签栏明确浏览器身份，青色路径表达访问和网络导航。
- 避免：监视器支架、地球 logo、指南针、搜索引擎品牌和网页截图。

### 平台日志

- 语义：结构化日志列表附带蓝色时间轴和小时间标记。
- 优点：日志流和时间顺序同时清晰，与终端和普通文档区分明显。
- 避免：只有普通列表、终端提示符、聊天消息、文本文档和代码截图。

### 通知历史

- 语义：通知铃放置在历史面板中，小历史标记位于角落。
- 优点：铃铛始终是主对象，历史信号保持次级，不误像普通闹钟。
- 避免：过大的白色时钟、邮件、聊天气泡、数字角标和独立闹钟。

## 使用方式

1. 生成前对照共同特征确定材质、光源和明度。
2. 选稿时比较新图标与已确认基准在 40px 下的视觉重量。
3. 不要求复刻具体几何造型；要求新图标像同一产品家族，而不是来自不同图标包。
4. 新图标经用户明确确认后，再将其语义优点和避免项补充到本文件。
